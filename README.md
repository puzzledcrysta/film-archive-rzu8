# 胶片修复拼接

面向电影资料馆修复员。先合并目标帧号区间，再减并集内已判废的帧段，帧号采用含尾区间。复算后按扫描段核对独立清单，查看单据证据和差值，再登记复核结论。

## 启动

```sh
docker compose up --build
```

默认访问 http://localhost:18282。
打开工作台，点击运行即可使用内置的班次样例。选择导入可以换成自己的来源与独立账 CSV。
样例在 `sample_data/`，`shift.csv` 有分页表头、冲突修订、坏行、空值哨兵与业务拒绝，`external.csv` 有单边与数值差异。
端口可通过 `APP_PORT` 覆盖。运行记录和复核历史保存在 `ledger` 卷。

## 补发语义

同一卷的后续修订只补变化的字段：业务字段**留空沿用上一版**，写 **`无` 明确清空**为空集合（如清空判废后扣帧恢复）。
折叠后仍不完整的卷以 `PATCH_INCOMPLETE` 隔离，不会把空白误当清空而少算可用范围。
工作台“帧段拼接”直接显示每卷最终可用帧段，证据面板给出每次补正后的可用帧段轨迹。

## 操作

- 在帧段拼接展开业务证据，核对原始字段、最终可用帧段与逐次补正轨迹。
- 在隔离裁决逐行检查原因。独立对账按键对比外部账并列出差值。
- 在批次复算重跑当前输入，同一补发重跑结果不变；切换失败时保留上一版并可继续打开。
- 在交付复核提交带版本意见，导出 JSON 证据包，或用“导出并账 CSV”逐卷合并正式结果与外部账差异。
